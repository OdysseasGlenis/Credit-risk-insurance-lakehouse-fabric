# Credit Risk & Insurance Lakehouse Modernization with Microsoft Fabric

Synthetic enterprise cloud data engineering project.

## Scenario
Migrate legacy banking/insurance analytical workflows into a Microsoft Fabric-style Lakehouse using Bronze, Silver and Gold layers.

## Skills demonstrated
- Fabric Lakehouse / OneLake-style architecture
- Data Factory-style orchestration
- PySpark / Spark SQL transformations
- Structured and semi-structured ingestion
- Data quality checks and monitoring
- Gold analytics marts for Customer 360 / Risk KPIs

## Build order
1. Upload `data/raw` and `data/reference` files into Fabric Lakehouse Files.
2. Create Bronze tables with metadata.
3. Create Silver cleaned tables.
4. Create Gold marts/features.
5. Add DQ checks and pipeline logs.
6. Add screenshots and architecture diagram.
